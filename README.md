# ❤️ Heart Disease Prediction App

A machine learning web application that predicts the possibility of heart disease based on patient health information.

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest
- HTML
- CSS
- JavaScript
- Vercel
